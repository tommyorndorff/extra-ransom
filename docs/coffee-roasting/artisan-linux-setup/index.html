Artisan on Headless Linux

How to set up a headless Ubuntu server as a Phidget sensor hub, so that Artisan running on your Mac can read the VINT thermocouples as if they were plugged in locally.

Architecture: the Ubuntu server runs the Phidget Network Server — a lightweight daemon that makes all attached Phidget devices available over the LAN via WebSockets on port 5661. The Mac’s Phidget22 library discovers it automatically, and Artisan sees the remote sensors transparently. No Artisan instance, no virtual display, and no VNC needed on the server.

Hardware

Section titled “Hardware”
  • Ubuntu server (22.04 or 24.04 LTS, headless)
  • Phidget VINT Hub (e.g. HUB0000_0) connected via USB
  • Thermocouple module(s) in VINT ports — e.g. TMP1101 (4-input K-type) or TMP1100 (single)
  • Mac on the same local network

1. Install the Phidget22 Library and Network Server

Section titled “1. Install the Phidget22 Library and Network Server”

Phidgets provides an apt repository for Ubuntu.

If you prefer not to run the setup script, download the packages directly from phidgets.com/downloads.

2. USB Permissions (udev Rule)

Section titled “2. USB Permissions (udev Rule)”

By default, USB devices are only accessible to root. Add a udev rule so the network server process can reach the Phidget Hub without running as root.

Log out and back in (or reboot) for the group change to take effect.

3. Confirm the Phidget Hub is Visible

Section titled “3. Confirm the Phidget Hub is Visible”

Plug in the VINT Hub, then verify USB enumeration and permissions:

If lsusb doesn’t show a Phidget, try a different USB port, check dmesg | tail -20 immediately after plugging in, or try a different cable.

4. Run the Phidget Network Server

Section titled “4. Run the Phidget Network Server”

The phidget22networkserver package installs a systemd unit. Enable and start it, open the firewall port, then verify the server is listening:

The server listens on port 5661 and publishes all connected Phidget devices over a WebSocket interface. It also advertises itself via mDNS/Bonjour so the Mac’s Phidget22 library can discover it without needing a static IP.

5. Configure Artisan on macOS

Section titled “5. Configure Artisan on macOS”

Install the Phidget22 drivers on your Mac

Section titled “Install the Phidget22 drivers on your Mac”

The Mac needs the Phidget22 library to talk to the network server. Download and install the macOS package from phidgets.com/downloads.

You do not need to physically attach any Phidget to the Mac.

Open Artisan and configure the device

Section titled “Open Artisan and configure the device”
  1. Launch Artisan on your Mac.
  2. Go to Config > Device.
  3. In the device list, select the Phidget module that matches your thermocouple board — e.g. Phidget TMP1101 for a 4-input K-type board.
  4. Set the channel assignments for ET (environmental/drum temp) and BT (bean temperature) to match how your thermocouples are wired to the VINT ports.
  5. Click OK.

Auto-discovery (same LAN, mDNS)

Section titled “Auto-discovery (same LAN, mDNS)”

If your Mac and the Ubuntu server are on the same subnet, the Phidget22 library discovers the network server automatically via Bonjour. No further config needed — just press ON in Artisan’s toolbar and you should see live ET/BT readings within a few seconds.

Manual server address (if mDNS doesn’t work)

Section titled “Manual server address (if mDNS doesn’t work)”

If auto-discovery fails (e.g. across VLANs, or mDNS is blocked), set the server address explicitly. Open a terminal on your Mac and add the server:

Or set it within Artisan: Config > Device, look for a Server or Remote field and enter <server-ip>:5661.

In Artisan (Mac):

  1. Press ON — ET and BT should populate within a few seconds.
  2. The status bar should show the Phidget device name without an error icon.
  3. Wiggle a thermocouple gently — the temperature reading should respond.

Troubleshooting:

Symptom Check
lsusb shows no Phidget `dmesg
networkserver fails to start journalctl -u phidget22networkserver — likely a permissions issue; verify plugdev group
Port 5661 not reachable from Mac sudo ufw status; confirm server IP is correct
Artisan shows no readings Confirm Phidget22 drivers installed on Mac; try phidget22admin -a <ip> to force address
ET/BT swapped Swap channel assignments in Config > Device
